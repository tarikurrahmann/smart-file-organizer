One mission, two implementations

Choose your desktop stack.

These are standalone applications with their own UI and file-operation code. Electron does not invoke the Python app.

Desktop UI

Electron.js + Tailwind CSS

An HTML desktop interface styled with Tailwind. JavaScript in Electron's main process performs file operations through a restricted preload bridge.

Electron shell / JavaScript services / Tailwind UI

Standalone core

Python + PyQt6

A separate Python desktop application with its own PyQt6 interface, organizer logic, local activity history, cleanup, and watcher services.
