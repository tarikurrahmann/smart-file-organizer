Integrations & workflows

Your folders.
Your workflow.

Smart File Organizer works directly with folders on your computer. No cloud account is required, and your files are not uploaded.

Local folders

Choose a folder on your device or drop files into the app. File operations run locally on the computer.

Available

Folder watcher

Watch selected folders while the desktop app is running and sort incoming files after they are saved.

Available in desktop app

Custom file rules

Set extension-to-folder rules to match the way you want files categorized.

Available in desktop app

System Trash

Duplicate cleanup moves selected items to the operating system Trash or Recycle Bin for review.

Available in desktop app

Activity & undo

Review local activity records and undo the latest organization action from the desktop app.

Available in desktop app

Cloud services & API

Cloud-drive connectors, webhooks, and a public integration API are not currently provided.

Not available
