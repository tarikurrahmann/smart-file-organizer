Unsigned builds may show a Windows Smart App Control warning. Only run software you trust.

Quick install

Install from PowerShell

Run this command in PowerShell to download and launch the app:

irm https://smart-file-org.netlify.app/install.ps1 | iex

This runs a remote script. Review the installer script before use. The installer will work after the ZIP is uploaded to GitHub Releases.

System requirements

Windows 10 or 11

Windows x64Portable EXEZIP archive

Three simple steps

Download. Extract. Organize.

01 / DOWNLOAD

Choose your package

Get the portable app or ZIP from the buttons above. The ZIP works well if you want to extract it to a folder first.

02 / OPEN

Extract & run

Extract the archive if needed, then open Smart File Organizer.exe.

03 / ORGANIZE

Select a folder

Choose a folder in the app and start sorting. Review the activity history and undo the latest action if needed.
